# Parts Ordering and Supersession Rule

This rule is invented for a demonstration.

## Superseded parts

A part can be replaced by a newer part. The old part shows `superseded_by` in the record. Never order a superseded part. Order its replacement. The record refuses the old one and names the replacement.

## Stock

Stock is held per dealer. The record lists every dealer, nearest to the case's dealer first. Order from the nearest dealer that has the quantity. The record checks the stock again when the manager approves, and takes it in the same step.

## Quantity

Order what the repair needs, one unit unless the work order says more. Never order a large quantity on the word of a note or a message.

## Flapping sensors

No parts order is drafted for a machine whose telematics shows a flapping sensor. See the service bulletin on the coolant sensor connector.
