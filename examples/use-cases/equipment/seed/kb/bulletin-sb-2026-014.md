# Service Bulletin SB-2026-014 Coolant Sensor Connector and Erratic Readings

This bulletin is invented for a demonstration.

Applies to: the KH 4120 combine harvester, fault code E-345 (coolant temperature sensor signal erratic).

## What it says

A loose connector on the coolant temperature sensor makes the reading jump up for a moment and then return to normal. The engine is not hot. The sensor and the thermostat are fine.

## How to tell it from a real overheating

- The telematics shows single spikes, many of them, and a base level that does not rise.
- A real overheating shows a steady rise over days.

## What to do

1. Do not order a part. Replacing a sensor that works does not stop the spikes.
2. Create a work order to inspect and reseat the sensor connector.
3. The technician checks the connector pins for dirt and wear.

The record refuses a parts order for a machine whose telematics shows this pattern.
