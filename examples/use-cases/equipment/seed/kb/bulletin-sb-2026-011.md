# Service Bulletin SB-2026-011 Coolant Temperature Fault E-317

This bulletin is invented for a demonstration.

Applies to: the KH 4120 combine harvester, fault code E-317 (coolant temperature high).

## What it says

Machines with the early thermostat part P-10006 can show a coolant temperature that rises over several weeks, then the fault E-317. The part drifts. The sensor reading is usually right.

The part P-10006 is superseded by P-10361. Always order P-10361. The record refuses an order for P-10006.

## What to do

1. Safety first: stop the machine and let the engine cool before anyone opens the coolant cap.
2. Read the telematics for the last 14 days. A steady rise of 8 degrees or more fits this bulletin.
3. Replace the thermostat with P-10361 and check the coolant hoses.
4. Test run the machine and read the coolant temperature again.

## Stock

P-10361 is often out of stock at the nearest dealer. Ask the record for the stock at every dealer, and order from the nearest dealer that has the quantity.

## Warranty

E-317 is a warranty item when the machine is inside its limits. The record decides.
